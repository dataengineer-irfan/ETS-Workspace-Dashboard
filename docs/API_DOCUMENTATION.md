Inventory of HTTP routes registered by `backend/app/main.py` and route decorators under `backend/app/routers/`. Fields are the Pydantic models or the dict keys the handlers return. Nested dict items inside `List[Dict[str, Any]]` or `Dict[str, Any]` are not given a fixed schema in `backend/app/models.py`; those inner keys are not invented here.

OpenAPI JSON is generated by FastAPI at `/openapi.json` (`backend/app/main.py`). Interactive docs: `/docs` and `/redoc`.

Default error body for `HTTPException` is FastAPI’s `{"detail": ...}`. There is no custom exception handler in `backend/app/main.py`.

The dashboard Axios client (`frontend/src/api/client.ts`) sends `Authorization: Bearer <ets_auth_token>` when that `localStorage` key exists. That header is not the same as a server dependency. A route is marked authenticated only when the handler uses `Depends(get_current_user)`, `Depends(require_roles(...))`, or the copilot token read described below.

## Shared dashboard query parameters

`GET` handlers that call `extract_request_filters` (`backend/app/analytics.py`) accept every query string key. Repeated keys and keys ending in `[]` are collected into lists.

`apply_employee_filters` in the same file applies these keys when present:

| Query key | Effect |
| :--- | :--- |
| `state` | `State` column |
| `project` | `Project Working` (value `NH` also matches `NH PROJECTS`) |
| `module` | `Module` column, if present |
| `job_level` | `JOB LEVEL` |
| `location` | `LOCATION` |
| `department` | `DEPARTMENT` |
| `manager` | substring match on `MANAGER` |
| `salary_bin` | `SalaryBin` |
| `skill_name` or `skill` | primary, secondary, or all skills |
| `tenure_band` | tenure bands inside `apply_employee_filters` |
| `emp_type` | employee type inside `apply_employee_filters` |
| `search` | text search inside `apply_employee_filters` |

Values `all`, `none`, `null`, `undefined`, and empty strings are dropped by `parse_filter_list`.

`FilterParams` in `backend/app/models.py` lists `state`, `job_level`, `location`, `department`, `project`, `manager`, `module`, `year`, `skill_name`, `salary_bin`, `search`. It is **not** the request model on these GET routes. The routes use the raw `Request` query string.

Calendar-only keys used in `get_calendar_data` (`backend/app/analytics.py`): `leave_type`, `employee_number` or `employee`, `year`, `month`, `date`, `start_date`, `end_date`.

`Pydantic` model `FilterParams` is defined and is not referenced by the router function signatures that were read.

### `POST /api/auth/login`

| | |
| :--- | :--- |
| Auth | None |
| Request model | `LoginRequest`: `username` (min length 1; matched as username or email), `password` (min length 1) |
| Response model | `TokenResponse`: `access_token` string, `token_type` default `"bearer"`, `user` (`UserResponse`) |

Lookup: `get_user_by_username_or_email`. Unknown user or bad password: HTTP 401 `Invalid username or password.` Inactive user: HTTP 403 `Account is disabled. Please contact your system administrator.`

Token claims built in the handler, then `create_access_token` adds `exp` and `iat` (`backend/app/security.py`): `user_id`, `sub` (username), `email`, `role`, `employee_number`. Algorithm `HS256`. Lifetime 24 hours unless a caller passes `expires_delta` (the login handler does not).

### `POST /api/auth/forgot-password`

| | |
| :--- | :--- |
| Auth | None |
| Request model | `ForgotPasswordRequest`: `username` string, min length 1 (username or email) |

## `backend/app/routers/dataset.py`

Prefix `/api/dataset`. Tag `Dataset Management`. Auth: none on these routes. No `Depends` import is used on the handlers (the file imports `Depends` and does not attach it to the decorators that were read).

There is no Pydantic request or response model in this file. Bodies below are the dicts the functions return or the parameters they read.

### `GET /api/dataset/status`

Request: none.

Response keys: `file_name`, `file_path`, `file_size_bytes`, `file_size_formatted`, `last_modified`, `source_type`, `cloud_url`, `last_synced`, `auto_sync_enabled`, `total_employees`, `total_skills`, `total_leaves`, `total_finance_records`, `backup_count`, `recent_backups` (up to 5 `.xlsx` names from `dump/backups`, sorted reverse).

### `GET /api/dataset/download`

Request: none.

Success: `FileResponse` for `data_loader.file_path`, media type `application/vnd.openxmlformats-officedocument.spreadsheetml.sheet`, download name `ETS_Dasboard_DS_export_YYYYMMDD.xlsx`.

Missing file: HTTP 404 `Master dataset file not found on server.`

### `POST /api/dataset/validate`

Request: multipart file field `file` (`UploadFile = File(...)`). Filename must end with `.xlsx` or `.xls` (lowercased). Otherwise HTTP 400 `Invalid file format. Only Excel (.xlsx) files are accepted.`

Response: dict from `_validate_workbook_bytes`: `valid` bool, and when parsing succeeds `sheets_found`, `counts`, `errors`, `warnings`, `size_bytes`. Early failures return `valid` false and `errors` only, or `errors` plus `sheets_found` when a required sheet is missing.

Required sheets: `EMPLOYEES`, `SKILL`, `Finance_History`, `LEAVE`. Required columns checked on a 5-row sample: see `REQUIRED_COLUMNS` in this file (`EMPLOYEES`: `EMPLOYEE NUMBER`, `START DATE`, `EMP_CTC1`, `GENDER`, `LOCATION`, `State`; `SKILL`: `EMPLOYEE NUMBER`, `Skill Name`; `Finance_History`: `EMPLOYEE NUMBER`, `Year`, `Base_Salary`; `LEAVE`: `EMPLOYEE`, `START DATE`, `END DATE`, `DAY VALUE`). `EMPLOYEES` and `LEAVE` use `skiprows=2`.

### `POST /api/dataset/upload`

Request: same multipart `file` rule as validate.

Invalid workbook: HTTP 400 `detail` object with `message`, `errors`, `warnings`. Master file is not modified in that branch.

Success JSON: `status` `"success"`, `message` the success string in the handler, `backup_path` (or null if no previous master), `metrics` (return value of `reload_all()`: `status`, `total_employees`, `total_skills`, `total_leaves`, `total_finance_records`), `validation_report`.

Failure after swap: HTTP 500 detail string that includes the exception text. The handler attempts to restore the timestamped backup and call `reload_all()` again.

Also writes `dump/dataset_config.json` with `source_type` `LOCAL_EXCEL` and `last_synced`.

### `POST /api/dataset/test-url`

Request: JSON object. The handler reads `payload.get("url")`. Missing or blank `url`: HTTP 400 `Missing required 'url' parameter.` No Pydantic model. Other keys are ignored.

Response when the HTTP client returns: `reachable` bool, and on HTTP 200 `status_code`, `is_valid_excel_header`, `content_type`, `size_bytes_hint`, `transformed_url`, `message`. On non-200: `reachable` false, `status_code`, `error`, `transformed_url`. On client exception: `reachable` false, `error`, `transformed_url`.

URL rewrite is `_transform_share_url` (SharePoint `download=1`, OneDrive `1drv.ms` and `onedrive.live.com`).

### `POST /api/dataset/sync-cloud`

Request: JSON object with `url`, same as test-url.

Remote non-200: HTTP 400. Invalid workbook: HTTP 400 `detail` with `message` and `errors`. Other exceptions: HTTP 500.

Success JSON: `status` `"success"`, `message`, `backup_path`, `metrics` (`reload_all()`), `cloud_url` (the raw URL). Config `source_type` is set to `SHAREPOINT_URL`.
