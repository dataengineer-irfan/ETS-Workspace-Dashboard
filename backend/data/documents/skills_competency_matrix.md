# Technical Skill Matrix and Proficiency Guidelines

Every delivery employee has recorded technical proficiencies mapped into the workforce competency registry.

## Skill Types
1. **Primary Skill**: The core foundational technology discipline an employee is formally certified for and actively deployed on for client projects.
2. **Secondary Skill**: Ancillary or supporting technical capabilities demonstrated through internal training, minor project assignments, or past experience.

## Proficiency Levels
- **Beginner**: Fundamental conceptual understanding with basic practical application under supervision.
- **Intermediate**: Independent delivery capability across standard module tasks, debugging, and code production.
- **Expert**: Deep architectural mastery, mentoring capability, and enterprise system troubleshooting.

## Core Competency Clusters
The authoritative technical registry tracks primary expertise across core clusters including Python, SQL, Java, React, Angular, Docker, Cognos, AWS, Linux, Informatica, and Quality Assurance Testing.
